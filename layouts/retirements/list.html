How we build this calendar

A scheduled job reads the official deprecation pages once a day, parses their tables and opens a pull request when anything changes, and a person reviews each date change before it goes live. We don't take data from third-party trackers.

  • For active Claude models, Anthropic publishes a "not sooner than" date. That's the earliest Anthropic could retire the model, so those dates stay off the calendar.
  • Google publishes the earliest possible shutdown date for Gemini API models, and the calendar labels those dates "earliest".
  • One OpenAI row often covers an alias and its snapshots, such as o3 and o3-2025-04-16. The calendar groups them into one entry.
  • Dates are for each provider's own API. Cloud platforms such as Amazon Bedrock set their own schedules.

The calendar feed gives each shutdown a stable ID, so if a provider moves a date, your calendar event moves too, with reminders 30 and 7 days before.
