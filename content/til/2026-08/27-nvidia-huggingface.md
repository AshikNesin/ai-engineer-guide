Nvidia owns the computing layer - powerful GPUs and things like that.

And HuggingFace is the distribution layer for open source LLM models, datasets and hosting. 

It's like defacto GitHub in AI/ML world.

And Nvidia agreed to buy HuggingFace for $13 billion. My guess is that it wants to control the full stack now. 

Neither of them officially acknowledged it. 

Honestly, it might destroy what made Hugging Face what it is today - open source. And I hope it does not become bad like GitHub post Microsoft acquisition
