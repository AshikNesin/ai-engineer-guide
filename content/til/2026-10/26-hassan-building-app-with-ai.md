Hassan (Director of DX at Together) has shared how he builds app with AI these days

You might have know him from his side projects like [self.so](https://www.self.so/) which uses AI under the hood and pretty much most of them are open source.


<blockquote class="twitter-tweet"><p lang="en" dir="ltr">How I build apps these days:

1. Record a 1-5 minute prompt with @WisprFlow The more detail, the better.
2. Add visual inspo so the agent knows what I have in mind (screenshots or Inspo MCP).
3. Use @mattpocockuk's grill-me skill to have the agent ask clarifying questions.
4. Get back a v1, then send a list of feedback, feature requests, and design tweaks (via another voice recording usually).
5. For each new feature, ask for a quick screen recording to verify it works before merging the PR.
6. Keep iterating until I'm happy, then post it on @X or throw it away.

For my harness, I use a mix of Claude Code with Opus 5.5 (high) and OpenCode with DeepSeek V4.1 Flash / GLM 5.3.

I also give my agents some CLIs &amp; skills:

• Vercel + GitHub CLIs so they can push code and deploy apps.
• Together skills so they can use chat, image, &amp; voice models from Together
• Design/animation skills so they have guidance on spacing &amp; interactions</p>&mdash; Hassan (@nutlope) <a href="https://x.com/nutlope/status/2114445139800461618?ref_src=twsrc%5Etfw">October 25, 2026</a></blockquote>
