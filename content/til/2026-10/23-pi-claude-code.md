[Armin Ronacher](https://github.com/mitsuhiko)'s [pi-claude-code](https://github.com/earendil-works/pi-claude-code) lets you use your Claude subscription with Pi by using `claude -p` under the hood.

This is an experimental extenstion for [Pi](https://pi.dev) which you can play around with but beware it may result in maxing out your usage sooner than using just claude code

## How to get started?

```
pi install https://github.com/earendil-works/pi-claude-code
```
